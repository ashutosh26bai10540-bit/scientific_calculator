# Project Statement

## Project Title
Scientific Calculator

## Problem Statement
Basic calculators do not always provide the scientific operations needed for quick academic and engineering calculations. Manual calculation of powers, roots, factorials, and trigonometric values can be inconvenient and error-prone. This project provides a simple command-line scientific calculator that performs common arithmetic and scientific operations through a menu-driven interface.

## Scope
The project covers arithmetic operations, powers, square calculation, square root, factorial, and trigonometric functions using degree input. It also includes input validation, division-by-zero handling, modular source files, and automated tests.

## Target Users
- Students learning programming and mathematics
- Users needing quick basic/scientific calculations
- Beginners demonstrating Python functions, modules, exception handling, and testing

## High-Level Features
1. Menu-driven calculator interface
2. Addition, subtraction, multiplication, division, and power
3. Square and square-root calculations
4. Factorial calculation
5. Sine, cosine, and tangent in degrees
6. Input validation and error handling
7. Modular Python architecture
8. Automated unit tests
